### Open source projects

- **[hushhook](https://github.com/monarchsofchaos004-gif/hushhook)**: Keeps secrets and big dumps out of your AI coding agent's conversation.
- **[splitaudio](https://github.com/monarchsofchaos004-gif/splitaudio)**: Android: keep the music app on Bluetooth and route every other app to the phone speaker.
- **[tooclose](https://github.com/monarchsofchaos004-gif/tooclose)**: Covers the screen when a child holds the phone too close.
- **[phoneguard](https://github.com/monarchsofchaos004-gif/phoneguard)**: Protects an elderly relative's phone from takeover scams.
- **[padcam](https://github.com/monarchsofchaos004-gif/padcam)**: Turns an old Android tablet into a self-hosted baby monitor.
- **[aibot-hostkit](https://github.com/monarchsofchaos004-gif/aibot-hostkit)**: One-command setup that keeps an AI coding agent running on a cloud Linux machine.
